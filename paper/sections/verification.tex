\section{Machine-checked proofs}
\label{sec:verification}

\Cref{thm:budget} is a statement about real numbers, while the code
computes margins, tolerances and aggregates in IEEE-754 double precision.
We check the floating-point implementation with
Kani~\cite{vanhattum2022kani}, a bounded model checker for Rust built on
CBMC~\cite{kroening2014cbmc} that encodes floating-point operations
bit-precisely. Each harness quantifies over all finite inputs of a fixed
shape, and over NaN and infinities where stated. The times below are
wall-clock times for Kani~0.68 (CBMC with CaDiCaL) on a 24-core x86-64
machine running 12 harnesses at once.

We first tried a single harness stating that the budget implies the same
condition, over a window of three samples. It did not finish in 6 hours for
any aggregate. Symbolic execution is fast, but the final SAT query over the
chain of floating-point operations (aggregate, subtraction,
\code{next\_down}, comparison) is too hard. We therefore prove
\cref{thm:budget} for \code{last}, \code{min\_over\_time} and
\code{max\_over\_time} in three parts. An abstract tolerance $\tau$
separates the expensive tolerance computation from the window structure:
\begin{enumerate}
  \item[(A)] \emph{Scalar tolerance}, one harness per comparison: if
    $\mathrm{fl}|y' - v| \le \tau(v)$, where $\tau$ is the implemented
    tolerance function, then $y'$ and $v$ are on the same side of $\theta$
    (56--69 min each).
  \item[(B)] \emph{Window lemmas} on at most four variables. The extremum
    is attained by some sample. For the arg-extrema $j$ and $k$,
    $\mathrm{fl}|y_j - x_k| \le
    \max(\mathrm{fl}|y_j - x_j|, \mathrm{fl}|y_k - x_k|)$ (198 and
    226 min). Rounded subtraction is monotone (130 min).
  \item[(C)] The implemented tolerance of a window equals $\tau(f(x))$
    bitwise ($\le 3$ min), and the aggregates are monotone
    (\cref{cor:onesided}; $\le 8$ s).
\end{enumerate}
Together, (A)--(C) give the floating-point version of \cref{thm:budget}
for these aggregates and every window length.

For the codec, we prove that the decoder reconstructs exactly the values
the encoder computed, bit for bit, for every block parameter and including
$-0.0$. We also prove the gauge and counter invariants of the quantizer.
The quantizer tries several candidate step counts (rounding, the lazy
choice, and one step inwards) and returns only a candidate
that passes a single acceptance check. A harness over the full candidate
search did not finish in 6 hours, so we prove the invariants for the
acceptance check applied to an arbitrary candidate (7 and 15 min, run
separately on a 16-core machine). Finally, we prove that the zigzag and
varint codes and the bit-level specification of the bit I/O round-trip.

\paragraph{Not yet proved.} \code{sum/avg\_over\_time} need a lemma on the
error of a rounded sum in place of (B). The range coder and the concrete
bit writer run out of memory or time in symbolic execution, because of
unbounded \code{Vec} growth and a loop bound that depends on a symbolic
counter. Property tests cover these parts. Round-trip tests run both
formats with NaN, infinite and zero budgets and with counters, and
$5 \times 2000$ random decision-preservation cases are checked against a
reference evaluator that recomputes every instant. The tests catch a
mutation that multiplies the budget by 3.
